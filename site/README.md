# Bungle Group — website rebuild (design draft)

A complete, refreshed website for **Bungle Group** — Australian food export &
supply-chain business. This is a static, hand-built draft used to lock the
design and copy before publishing in Wix.

## How to view

Open `index.html` in any browser. All pages share `styles.css` + `main.js`
and link to each other, so keep the folder together. Fonts load from Google
Fonts (needs an internet connection).

## Pages

| File | Page |
|------|------|
| `index.html` | Home |
| `about.html` | About — story, evolution timeline, key facts |
| `what-we-do.html` | Export · Procurement · Supply chain & 3PL · Domestic produce |
| `markets.html` | Markets — PNG/Pacific, mining, government/UN, airline, hotels, retail |
| `products.html` | Products — fresh, frozen, dairy, FMCG + seasonal calendar + fruit exports |
| `quality.html` | Quality — certifications explained, integrity, security |
| `contact.html` | Contact / get a quote |

## Design system — "Logistics dossier"

- **Palette:** warm paper `#F6F4EF`, warm near-black ink `#16140F`, brand red
  `#ED3E38` (the single accent), warm near-black panels for gravitas sections.
- **Type:** Archivo (display), IBM Plex Sans (body), IBM Plex Mono (data /
  manifest labels), Fredoka (logo lockup).
- **Signature device:** proof points, certifications, SKUs and coordinates set
  as monospace "shipping manifest" data rows; one cargo-ticker motion moment.
